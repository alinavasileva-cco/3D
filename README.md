# КАБИНЕТ 1.0 — Three.js 3D-тур

Интерактивный тур комнаты, экспортированной из Blender. Оригинальная рабочая сцена `КАБИНЕТ 1.0.blend` остаётся на компьютере. Модель, мебель, ракурсы и материалы в этом репозитории не меняются при публикации.

## Публикация через GitHub Pages (бесплатно)

Публикуется **существующий** репозиторий `alinavasileva-cco/3D`. Новый репозиторий, Cloudflare или платный тариф не требуются.

После переключения GitHub-репозитория в **Public**:

1. Перейти в https://github.com/alinavasileva-cco/3D/settings/pages
2. В разделе **Build and deployment** установить **Source → GitHub Actions**.
3. Перейти в https://github.com/alinavasileva-cco/3D/actions/workflows/pages.yml
4. Нажать **Run workflow** для ветки `main`, если сайт не был опубликован автоматически.
5. После зелёного статуса **Deploy** открыть опубликованную ссылку, указанную GitHub в Pages или в журнале workflow. Ожидаемый адрес: https://alinavasileva-cco.github.io/3D/

⚠️ При переключении репозитория в Public исходные файлы репозитория, GLB, изображения и вся его история становятся общедоступными. Перед изменением приватности убедиться, что это допустимо. В репозитории нет рабочего `.blend`, но есть экспорт модели комнаты.

## Структура

- `index.html` — Three.js-тур кабинета: камеры, движение, дневной/ночной режим, прозрачность стен и панель материалов.
- `cabinet_room.part01.bin` — `cabinet_room.part05.bin` — пять фрагментов одной экспортированной GLB-модели.
- `cabinet_photo.png` — изображение кабинета.
- `forest_background.png` — изображение окружения.
- `build_site.py` — проверяет файлы, восстанавливает цельный `cabinet_room.glb`, формирует папку `dist` для публикации, без изменения геометрии.
- `.github/workflows/pages.yml` — автоматически проверяет сборку и, если репозиторий Public, публикует на GitHub Pages. В приватном состоянии деплой пропускается.
