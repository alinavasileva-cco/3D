# КАБИНЕТ 1.0 — интерактивный 3D-тур (Three.js)

Точная ранее экспортированная версия комнаты из Blender, перенесённая в приватный репозиторий. Основной рабочий файл `КАБИНЕТ 1.0.blend` остаётся на компьютере; он не меняется при публикации.

## Бесплатная публикация из приватного GitHub через Cloudflare Pages

GitHub Pages для этого приватного репозитория на текущем тарифе недоступен. **Не нужно оплачивать GitHub или менять приватность репозитория.**

1. Перейти в **Cloudflare**: https://dash.cloudflare.com/ → **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**.
2. Подключить **GitHub**, выбрать аккаунт `alinavasileva-cco` и предоставить Cloudflare доступ к **единственному репозиторию `3D`**, если GitHub предложит выбор.
3. Выбрать репозиторий **`alinavasileva-cco/3D`** и основную ветку **`main`**.
4. **Framework preset:** `None` / `No framework`.
5. **Build command:** `python3 build_site.py`.
6. **Build output directory:** `dist`.
7. **Root directory:** корень репозитория (`/` или оставить поле пустым).
8. Нажать **Save and Deploy**. После успешной сборки Cloudflare покажет реальный публичный адрес вида `https://<выбранное-имя>.pages.dev`. Не используйте пример адреса до появления подтверждённого URL в панели.

После первоначального подключения каждый новый коммит в `main` автоматически запускает публикацию. Сайт публичен, но GitHub-репозиторий **остаётся приватным**. Публичные посетители смогут загрузить опубликованные GLB и текстуры, поскольку это ресурсы сайта. При необходимости ограниченного доступа к самому сайту его нужно настраивать отдельно.

## Исходники и сборка

- `index.html` — существующий Three.js-тур комнаты с камерами, дневным/ночным освещением, прозрачностью стен и информацией о материалах.
- `cabinet_room.part01.bin` … `cabinet_room.part05.bin` — пять последовательных фрагментов **одной** GLB-модели (в сумме 10 104 552 байта).
- `cabinet_photo.png` — рендер комнаты.
- `forest_background.png` — окружение.
- `build_site.py` — собирает части в `dist/cabinet_room.glb`, проверяет заголовок, glTF 2.0, размер и SHA-256, копирует в `dist/` HTML, изображения и части GLB, на которые ссылается существующий HTML.
- `.github/workflows/pages.yml` — **бесплатная проверка и ZIP-архив сайта** в GitHub Actions. Не пытается запускать GitHub Pages.

**Проверенный GLB SHA-256:** `1ba8304d90217b3c97f021cda9a4d7b2ce4e69716408549033ffde3685185648`. Если экспорт комнаты изменится, необходимо проверить новую модель и обновить контрольную сумму в `build_site.py`. Это защищает от незаметной подмены согласованной версии.

Собрать локально при необходимости: `python3 build_site.py`. Запускать сайт через HTTP-сервер, а не открывать HTML в браузере по `file://`, поскольку он использует `fetch()` для GLB.

## Без платного тарифа

Используем **Cloudflare Pages Free**: поддерживаются как приватные, так и публичные репозитории GitHub, 500 сборок в месяц на бесплатном плане, максимальный размер одного файла 25 MiB. Цельный GLB кабинета — примерно 9.6 MiB, что меньше ограничения.
