# КАБИНЕТ 1.0 — Three.js

Интерактивный 3D-тур комнаты из Blender. Основной рабочий файл Blender остаётся на компьютере под именем `КАБИНЕТ 1.0.blend`.

## Структура

- `index.html` — сайт Three.js с просмотром кабинета, дневным и ночным режимами, настройкой прозрачности стен и просмотром материалов.
- `cabinet_room.glb` — экспортированная геометрия и PBR-материалы комнаты.
- `forest_background.png` — панорама окружения.
- `cabinet_photo.png` — реальный рендер Cycles.

Публикация сайта должна сохранять исходный GitHub-репозиторий приватным. Веб-ресурсы после публикации доступны посетителям сайта.
